# High-Quality PBR Texture Assets

The live GitHub Pages build generates the Starter Texture Pack into this directory during CI.

Quality contract:
- native source generation: 2048×2048 minimum
- no low-resolution upscaling
- no pixel-art source for Stylized High Quality skins
- runtime 1024/512 copies are derived only after the 2K master exists

Generated map types include BaseColor, Normal, Roughness, Metalness, AO and Emissive.
