# V1.8 Source Pointer

The deployable V1.8 Studio source is stored losslessly in `deploy/source_v1_8/` as an XZ-compressed source blob.
`scripts/build_pages.py` reconstructs the exact `index.html` during CI before GitHub Pages deployment.
High-resolution PBR starter textures are reproducibly generated by `scripts/generate_textures.py` and verified before deployment.
